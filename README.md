# 🚀 DocuMind AI

AI Powered Repository Documentation Platform

Built for AI Hackathon 2026 at Technocrats Institute of Technology Bhopal.

---

## 🔥 Features

### 🤖 AI Documentation Generator
- Generate README documentation
- API documentation
- Setup instructions
- Architecture explanations
- Deployment guides
- Optimization suggestions

### 💬 AI Repository Chat
Chat directly with uploaded repositories.

Ask questions like:
- Explain authentication flow
- Which APIs are used?
- Explain folder structure
- How database works?

### 📊 Analytics Dashboard
- User analytics
- Repository analytics
- AI usage statistics
- Project history
- Health score tracking

### 👑 Admin Panel
- Ban/Unban users
- Warning system
- Delete users
- Monitor platform usage
- Manage users

### 📄 Export Features
- Export documentation as PDF
- Download generated reports
